# Witch Girl · 安卓离线版

这是针对 KooooNSoft《Witch Girl》（日文 v2.20）的非官方 Android 封装。

## 下载

**[下载 v1.2.0 性能与适配修复 APK](https://github.com/NLKASHEI/-/releases/download/v1.1.0/Witch-Girl-Offline-v1.2.0.apk)**

v1.0.0 因缺少人物素材、场景和背景音乐，**已知不完整，不建议安装**。

## v1.2.0（性能与屏幕适配）

- 游戏**内部画面**填充按键之间的可用区域，不再强制固定 728:529 的黑边。默认是铺满（可能轻微拉伸），可以点左上角「画面」改回不变形的等比模式，或者选择等比裁切。
- **Ruffle 画质默认降为低**，降低多重采样的 GPU 负担；可在「画面」切换中等画质、标准渲染（兼容优先）、快速渲染（特效支持可能较少）或软件渲染（非常慢，应急）。
- 修复 Android WebView 渲染进程意外退出后的处理，重建 WebView；检测到部分 WebGL 上下文丢失时会尝试重载游戏，亦可通过「画面」→「恢复画面」手动恢复。
- SWF、WASM、MP3 不在 APK 内重复压缩，降低读取时的额外解压开销。运行仍然完全离线。
- 原有自动存档和导入/导出功能保留。
- **注意**：只是针对截图反映的问题做了针对性优化，尚没有手机实测证明完全杜绝白屏。切换渲染或恢复画面会重新进入游戏标题，请先使用游戏自己的存档功能。

## v1.1.0 基础修复内容

- 主游戏 SWF + **56 个外部 SWF**（包括人物/场景/画廊）+ **7 个原始关卡 MP3**，编译时获取并全部打包进 APK。安装后无需联网。
- 修正横屏游戏画面的宽高比（728:529），并给左右触屏按键留出独立区域，避免按钮挡住游戏。
- 方向键 ↑↓←→ + Z/X/C，支持多指同时按下和长按。
- **持久化保存游戏自身的 Flash SharedObject 数据**：WebView DOM Storage + 每 2.5 秒自动快照到应用私有目录，应用重新打开时必要时恢复。
- 屏幕右上角 **「存档」** 可备份当前已有存档、导出 JSON、从文件导入 JSON、重启游戏。
- 导出存档文件后可以在重装或换手机后再导入；**仅卸载应用而不导出，Android 会删除应用内保存的数据**。

## 安装/升级注意

**v1.0.0 使用了临时调试签名**，新版无法保证在 Android 上直接覆盖旧版。如果安装提示签名冲突，请先备份旧版能保存的数据，再卸载 v1.0.0 并安装 v1.1.0。旧版没有导出存档功能，因此无法提供可靠的无损迁移方法。

v1.1.0 起 GitHub Actions 缓存签名密钥，v1.2.0 使用相同密钥，正常情况下可覆盖安装 v1.1.0（**请勿卸载原版，否则可能丢失存档**）。

## 兼容性状态

v1.2.0 已通过 Android 编译及 APK 包内资源检查（共 56 SWF、7 MP3），**尚未完成 Android 真机人物渲染和存档读写实测**。Ruffle 自身已有对该游戏的文字/数字渲染兼容性问题报告，资源补齐并不必然解决字体问题。
